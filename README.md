# PitchSlap Pro ⚡️

AI that brutally roasts your pitch deck in 30 seconds and tells you how to fix it.

No sugar-coating. Only real investor feedback.

Built by Bericch Technologies, Kumasi, Ghana.

## 🚀 Live Demo
https://pitchslap-pro.netlify.app

## What it does
- Upload your pitch deck (PDF / PPT)
- AI analyzes: problem, solution, market, business model, traction
- Get brutal roast + actionable fixes in 30 seconds
- Improve and get funded
